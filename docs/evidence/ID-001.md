# ID-001 evidence: canonical Editor identity

Candidate: Atlas Builder Claude A, branch `agent/atlas-builder-claude-a/abdf9d0bc62d`.

## Change

- `src/atlas_commander/identity.py`: resolves an Editor observation (Monday Editor people-column value plus source evidence) to an `EditorIdentity` record through an explicit, versioned `IdentityMapping` keyed by Monday person ID. Every resolved identity is validated against `contracts/editor-identity.schema.json` before it is returned.
- `tests/test_identity.py`: identity fixture tests (16 tests).

## Quarantine rules (exception output, never guessed)

| Code | Trigger |
| --- | --- |
| `MISSING_EDITOR` | Editor column has no Monday person ID (empty list or empty string). |
| `AMBIGUOUS_EDITOR` | More than one distinct person in the Editor column, or the person ID maps to more than one canonical record in the mapping version. Candidate editor IDs are listed. |
| `UNMAPPED_EDITOR` | Person ID is absent from the mapping version. Display names or editor IDs passed in place of a person ID land here, so there is no name-based or fuzzy match. |
| `MISSING_EVIDENCE` | The observation is not an `editor_column_event` with a source `event_id` and `observed_at`. A `current_assignee` snapshot is always rejected as the historical Editor. |

Every exception records board/item/column IDs, the observed person IDs and the `mapping_version`, so it can be traced back to Monday. `resolve_all` splits a batch into contract-valid identities and exception dicts deterministically.

## Assumptions

- The mapping file format is `{"mapping_version": str, "entries": [{"monday_person_id", "editor_id", "display_name"}]}`. Any missing field raises `MappingError`, so a malformed mapping cannot produce partial identities.
- Identical duplicate mapping entries collapse to one record. Entries for the same person ID that disagree are ambiguous.
- Integer Monday person IDs are turned into their decimal string form. No other normalization is applied (no case folding and no whitespace trimming).
- The only accepted historical source is `editor_column_event`, meaning an Editor column value pinned to a Monday activity event. The ATTR-001 / CYCLE-001 integration will need to build these observations from normalized events.
- Many-to-one mappings (several person IDs → one `editor_id`) are allowed, which covers an Editor with multiple Monday accounts.

## Contract impact

None. `contracts/editor-identity.schema.json` and `common.schema.json` are unchanged. The exception record is an internal output with no contract yet. If it gets persisted or exposed, a contract owner should add `editor-identity-exception.schema.json`.
