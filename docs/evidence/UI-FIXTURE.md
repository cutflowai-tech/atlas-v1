# UI-FIXTURE · builder-1 evidence

Implemented an isolated, dependency-free Editor Profile under `web/`. It fetches `/api/editors/<editor_id>` and displays API quality, speed grouped by canonical Video Type, deadline and revision context. Every displayed metric includes an expandable complete Monday evidence record. Loading, empty, unknown, request failure and unsupported identity/evidence states are explicit. The fixture banner is permanent. No client metric arithmetic, composite score or AI annotation is rendered.

## Assumptions and limitations

The API owns approved label mappings, canonical Video Type resolution and all metric calculations. UI guards are deliberately narrower than full schema validation. Contract 1.0.0 exposes identity and quality mapping versions but no Video Type mapping version; no field or alias is invented. Empty deadline metrics cannot indicate which omitted cycles lacked ETA, so supplied cycle ETA is displayed separately without inferred results.

The HTML artifact verifies the fixture fetch-to-render path using an injected fetch and a minimal render target. It is not a real-browser E2E execution or screenshot. Browser layout, native evidence expansion and live HTTP smoke testing were not executed because no browser runner was installed and services/background work were prohibited. Native semantic HTML supports manual inspection. Demo command: `make -C web demo`; URL: `http://127.0.0.1:8080/?editor_id=editor-42`. No services were started.
